# 当前实验结果分析

本文保留当前 A/B 实验的分析逻辑，不引入新的实验结论。当前 C 组尚未形成正式结果。

## 1. 当前已完成实验

### A 组

* `H=1`：zero-shot
* `H=5`：zero-shot

### B 组

已完成的 `H=1` 变体：

* 默认：`lr=5e-5, bs=32, ep=10`
* `lr=2e-5, bs=32, ep=10`
* `lr=1e-5, bs=32, ep=5`
* `lr=1e-5, bs=64, ep=10`

已完成的 `H=5`：

* `eval-only`，复用 `H=1` 默认模型

### 当前解释前提

当前 B 组是：

* 按 `val loss` 选模
* 再用 `RankIC / IC / top-k / long-short` 做最终比较

因此下面的结论应理解为：

* “在当前 `val loss` 选模协议下，各配置的下游金融指标表现”

### 结论

当前默认 B 组仍是所有 B 组里最强的一版，但它没有在最核心的 `mean_rank_ic` 上超过 A。

更准确地说：

* 如果主看排序指标，A 组仍然更强
* 如果更看 `IC / top-k / long-short`，默认 B 组明显更强

所以当前不能简单写成“B 整体优于 A”，只能写成：

* B 组在收益可转化性和线性区分度上更强
* 但在最严格的排序指标 `mean_rank_ic` 上仍未超过 A

* `lr=1e-5, ep5` 这类更保守配置在验证集上已经明显偏弱

* 这可以作为迁移现象的证据
* 不能替代正式的 `H=5` 单独训练结果

## 5. 训练动力学分析

当前几组 B 组实验呈现出一个比较清楚的模式：

* `lr=5e-5`：token `val loss` 不漂亮，但下游金融指标最好
* `lr=1e-5`：token `val loss` 更稳，但下游金融指标更弱
* `lr=2e-5`：介于两者之间

这说明：

* `val token loss` 和下游金融指标并不单调一致
* 当前训练目标与最终任务目标存在错位

更具体地说：

* 学习率太大时，模型更容易偏离预训练分布，token loss 变差，但下游信号可能更强
* 学习率太小时，模型在 token loss 上更稳定，但任务适配不够，金融指标提升有限

## 6. 当前最合理的结论

### 已经可以确认的

* 微调是有价值的，至少在 `IC / top-k / long-short` 这些维度上，默认 B 组优于 A
* 但当前还不能说“B 全面优于 A”，因为 `mean_rank_ic` 没有超过 A
* `val loss` 不是金融任务下足够可靠的优劣标准

### 还不能确认的

* B 的最优正式配置是什么
* `H=5` 的正式最优配置是什么
* C 是否能稳定优于 B

## 7. 下一步建议

### 1. B 组继续细化学习率与 epoch

建议优先搜索：

* `lr=3e-5`
* `lr=5e-5, ep=5`
* `lr=3e-5, ep=15`

理由：

* `5e-5` 的任务适配最强，但 token loss 过拟合明显
* `1e-5` 太保守
* 中间区间仍有优化空间

### 2. `H=5` 做独立训练

正式实验里：

* `H=5` 应单独训练
* 当前 `eval-only` 结果只保留为参考

### 3. C 组在 A/B 口径稳定后再启动正式比较

启动 C 组前至少确认：

* B 组基线配置稳定
* B/C 股票池可对齐
* 当前比较语义明确：仍然是 `val loss` 选模

### 4. 后续若要升级为正式口径

需要做两件事：

* 用 `val mean RankIC` 选模
* 保证 B/C 在完全相同股票池上比较

在此之前，当前结果分析仍然成立，但要始终带着“当前选模协议”的限定。
